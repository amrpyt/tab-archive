## Fixes found during real testing
1. Idle countdown formerly started when tab opened/selected, not **after leaving** it.
2. `onCreated` may see `chrome://newtab` before URL; provisional record must survive.
3. Loading same URL must not clear dirty-form protection.
4. Paused new tabs must not become stale auto-close candidates after resume.
5. Hard-coded Notion token prefixes rejected future valid tokens; server now validates.
6. Browser restart must purge persisted tab IDs without relying solely on `runtime.onStartup` (which the driver did not always deliver).
