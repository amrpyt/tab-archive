# تاباتي — إضافة كروم

احفظ التبويبات الخاملة في نوشن تلقائيًا. بعد نجاح الحفظ، التبويب يتقفل. الروابط تفضل عندك.

**حالة التشغيل (٢٧ أكتوبر):** تكامل `Tab Archive V1 Private` مربوط وشغال على كروم الاختبار المعزول. حفظ رابطين بعد خمول ٥ دقائق في نوشن الحقيقي، واتقفلت التبويبات بعد تأكيد الحفظ. تجربة منع التكرار وحماية التبويب المثبّت والإيقاف المؤقت نجحت. مدة الخمول رجعت لـ٥ دقائق، والحفظ مفعّل. **الأمان:** المفتاح القديم اتكشف في المحادثة؛ تجديده موصى به ولو المستخدم اختار يحتفظ بيه.

## التثبيت

**تجربة آمنة منفصلة:** شغّل `فتح-كروم-منفصل.ps1` من PowerShell. يفتح Chrome for Testing بإضافة جاهزة وملف شخصي مستقل.

**تثبيت على كرومك الأساسي بعد التجربة:**

1. افتح `chrome://extensions` وشغّل **وضع المطور**.
2. اضغط **Load unpacked** واختار مجلد `extension`.
3. افتح [تكاملات نوشن](https://www.notion.so/profile/integrations). سجّل دخول، واعمل تكامل **داخلي خاص** بصلاحية قراءة وإضافة صفحات.
4. افتح [أرشيف التبويبات](https://app.notion.com/p/317f30f5a9cf4e3ea7a8ed034b91e3c1)، وشاركه مع التكامل من **Connections**.
5. افتح الإضافة. الصق المفتاح داخلها **فقط**. اضغط **اربط نوشن**، وبعدها **تشغيل**.

**مهم:** بلاجن نوشن في ChatGPT مش بيسلّم مفتاح API للإضافة. إنشاء التكامل وتفويضه لازم يحصل من داخل حسابك. متبعتش المفتاح في الشات.

**اختبار التشغيل الحقيقي:** جرّب ٣ تبويبات عادية جديدة. سيب كل واحدة بالخلفية ٥ دقايق. اتأكد إنها اتحفظت في نوشن قبل ما تتقفل. لو الحساب مش مربوط، الحفظ والتقفيل متوقفين.

**الأصل:** ٥ دقايق خمول. تقدر تغيّر المدة، توقف الحفظ، وتضيف استثناءات.

**English interface:** اضغط `English` أعلى الإضافة للتبديل الفوري إلى الإنجليزية. اللغة بتتحفظ، والاتجاه بيتحول تلقائيًا إلى LTR. قواعد التصنيف بتقبل `Programming`, `AI`, `Religion`, `Design`, `Work`, `Other` أو المقابل العربي. السجلات تفضل بنفس التصنيفات الأصلية في نوشن.

**الخطوط:** الإضافة تفضّل `Point R` لو مثبت على الجهاز؛ ولأن ملفاته وأوزانه المرخّصة غير متاحة بشكل موثوق، تضمّن `IBM Plex Sans Arabic` بالأوزان 400/500/600/700 كبديل ثابت، و`Inter` المتغيّر للإنجليزية. تراخيص OFL داخل `extension/fonts/`، وكل الخطوط محلية بدون اتصال بخدمة خطوط خارجية.

**الأمان:** التبويبات الحالية مش هتتقفل فجأة. التبويب النشط، المثبت، الصوت، النماذج المعدلة، والصفحات الحساسة مستثناة. عند فشل نوشن، التبويب يفضل مفتوح.

**الرجوع:** افتح [أرشيف نوشن](https://app.notion.com/p/317f30f5a9cf4e3ea7a8ed034b91e3c1) أو اضغط على آخر محفوظات داخل الإضافة.

**الخصوصية:** الإضافة تبعت العنوان والرابط والتاريخ والتصنيف والوسوم فقط لنوشن. مفيش محتوى صفحات ولا تفريغ يوتيوب في V1. المفتاح محلي داخل كروم، ومش بيتحط في الكود أو التوثيق.

**الاختبارات:** `npm test` (Node 20+). ملفات التطوير والمواصفات في `docs/`.
